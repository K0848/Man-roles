# 浏览器演示动图

先明确要证明的用户流程、数据来源和交付位置。普通 UI 修改不自动要求 GIF，也不因本技能而授权真实 API、发布媒体或修改 PR。

## 录制

确认源码版本、服务地址、构建方式与是否使用真实 provider。使用独立数据目录和浏览器上下文，不读取作者私人状态；若任务明确要求沿用现有状态，说明证据边界。不得打印凭据。

同一故事的所有帧来自同一次服务、数据根、workspace、会话和场景。自动化失败后重新录制，不拼接不同运行。只停止明确拥有的 PID 或准确进程，不用广泛进程匹配。

使用可用浏览器工具；缺失时仅用仓库已声明的 Playwright 与隔离无头浏览器，不擅自安装驱动或启动用户浏览器。依靠唯一可观察 UI 条件等待，截图只读演示状态；固定延迟、用户输入回显或模型自述不证明操作完成。涉及工具拒绝或恢复时，包含工具身份、状态和下游结果。

选择少量有意义状态，保持视口和裁剪一致，按顺序命名帧。截图与输出放在被忽略目录，避开密钥、个人信息和无关窗口。

## 编码与核对

使用本技能已有 `scripts/encode_gif.py`，需要 Python、ffmpeg 与 ffprobe；缺失时说明，不自行安装。先提供准确输入和输出路径，再设置持续时间、宽度、帧率和颜色。只对明确输出使用覆盖选项。

读取编码摘要，核对源帧和输出帧、尺寸、时长、体积及真实输出位置。查看编码后的 GIF；必要时从成品解码代表帧检查顺序和末帧停留，源截图不能证明成品正确。交付本地成品并说明真实 API、fixture 或其他传输方式。

## 可选远端附件

只有任务明确包括附件发布时才执行。媒体使用独立 assets 分支，不进入产品源码分支；推送前核对载荷和本地成品，之后验证远端真实字节。更新 PR 说明前后核对当前 head 与演示版本一致，不擅自改写、删除或强推已有媒体历史。远端操作按用户明确授权范围执行。
