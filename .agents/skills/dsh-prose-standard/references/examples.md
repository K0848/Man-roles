# 文字取舍示例

这些例子用于 [文字标准](../SKILL.md)，帮助判断删改是否保留了必要契约，不按字数选最短版本。

| 场景 | 应保留的说明 | 常见问题 |
| --- | --- | --- |
| 注册与释放 | 注册是同步操作，卸载时移除贡献 | 只写“需要清理”，或逐行复述 disposer |
| 真实装配验证 | 经过 Loader，检查外部输出与释放 | 只写“添加测试”，或列全部 fixture 文件 |
| 异步所有权 | 释放子 scope 前请求取消，provider 等待 worker 收敛 | 省略谁负责等待，或记录 promise 实现过程 |
| 事件时间 | 首次请求前组成前缀，listener 追加进入同次请求 | 只写“缓存前缀”，丢掉先后关系 |
| 公共失败 | 未初始化或已释放时抛错 | 只写返回值，或列全部内部状态分支 |
| 安全权限 | 挂载插件拥有 Host 权限，例如 shell 可执行 Host 命令 | 把一句边界展开为假设攻击清单 |
| 生成摘要 | 单独说明职责、策略顺序及审计后果 | 首句只是模糊名词，依赖后文才能理解 |
| 已实施决策 | 保留已验证行为、验证层级及具体缺口 | 删掉全部验证，或逐文件叙述断言 |
| 长期限制 | 配置改变需要重载，因为 provider 选择缓存到插件释放 | 把私有 helper 清理列成消费限制 |

代码已表达的分支无需再解释。非显然不变量则直接写该不变量；原因保留在一个拥有者处，其余链接过去。配置注释解释接线中看不出的顺序、安全或回放影响，不朗读相邻配置项。

模型可见稳定文本由拥有该文本的包准确引用，其他包链接其 schema 或消费契约；不复制另一套可能漂移的描述。短句若丢掉错误类别、时序或后果，保留原句更合理。
