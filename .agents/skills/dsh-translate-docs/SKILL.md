# 指定文档翻译

先确认指定源文、目标读者、目标语言和交付位置。此技能不建立英中同权镜像、配对记录、自动回录或跨文件同步任务；当前维护规则见 [语言政策](../../../docs/development/language/README.md)。

按原意保留事实、限制、代码与真实链接；术语资料只作参考，未知事实不补造。不执行已退役的翻译 brief、pairing verifier 或 merge driver。翻译不自动扩大为子 Agent、远端发布或原文改写授权。

只验证交付目标的准确性、格式和链接；历史材料按准确授权处理，保留仍有效的事实。
