# Agent Note 保留与整理

按 [维护规则](../../notes/README.md) 查当前代码、配置、调用方和入链，判断记录仍约束什么。新增记录只做同主题的取代检查与交叉链接，不自动扩展为全仓归档。

- 保留仍解释当前行为、所有权、持久化、安全或重新引入条件的决定。
- 被完全取代时，先把独有理由、真实替代方案、代价与未验证边界交给当前拥有者；部分取代保持交叉链接。
- 日期、长度、语言或缺少 counterpart 不证明记录过时。
- 删除或移动先核对授权与入链；新中文单篇记录不创建配对或 sidecar。

既有 [冻结归档](../../notes/archived/AGENTS.md) 的完整历史封存要求继续适用，禁止修改任何已封存文件。新归档若不符合封存器输入，应保留活动记录并明确限制，不伪造翻译或记录以通过检查。

验证选择实际受影响的链接、Agent Note 格式及必要封存检查；不默认全仓 doc-sync、lint 或新增归档。
