# 文档站同步

仓库 Markdown 是内容来源，[website/docs.ts](../../../website/docs.ts) 选择公开页面，[投影器](../../../scripts/project-doc-site.ts) 写入可再生的 `website/.generated/`。先读当前类型与映射，不能从语言后缀推断必须存在另一语言。

## 内容与路由

- 编辑已发布内容时只改拥有它的源文件；新增、移动或移除页面同步修改映射和入链。
- 中文是主要人工维护语言。活动页面只读取一份中文 canonical `.md`；不要创建 sidecar、调用翻译配对或补写无需求镜像。
- `canonicalPages()` 发布同一份 canonical 正文到实际所需兼容路由；不要把站点 locale 反向解释为人工翻译义务。
- 生成目录和生成区域修改其源码或生成器，不手改输出；不在 `website/` 添加正文或复制文档树。
- 根和 `/en/` 路由是发布结构，不代表正文必须使用某种语言。不要把私有台账、内部验收或决策记录因目录存在而自动公开。

## 链接

源文档使用正常相对链接。已映射文件投影到站点路由，其他存在的仓库文件可链接源码；图片必须是仓库内实际文件。保留所需标题锚点，不用虚构文件或翻译修复断链。

## 验证与发布

源文字检查格式与链接；修改映射时运行对应投影测试；修改路由、资源或 VitePress 行为时检查文档站构建。只在需要人工预览时启动服务，不默认执行全仓 doc-sync 或 lint。记录真实结果和未验证范围。

内容同步和本地构建不等于互联网发布；域名、托管、部署配置或远端修改需要对应任务授权。
