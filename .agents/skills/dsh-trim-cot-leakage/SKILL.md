# 清理过程叙述

先确认指定范围；分析只报告，已授权修改则直接处理明确问题。不触碰 vendor 原文、冻结归档、机器快照或真实数据。

查找实施步骤复述、无出处编号、旧草稿章节、审查者口吻、反复辩护、已实施记录里的计划语气，以及没有行为含义的状态声明。搜索模式只是候选，不能按命中数量机械删除。

保留真实接口义务、错误与失败范围、顺序和清理条件、安全边界、必要的实现方向，以及有依据的 lint/coverage 豁免与空 catch 解释。历史决策中的替代方案与后果是必要记录，不等于推理泄漏。

先修改事实拥有者：生成内容改源码或模板，类型粘贴跟随权威声明，模型或用户可见字符串按行为变化验证。人工正文统一中文单篇，不维护配对或回录。

验证受影响的格式、链接和必要类型契约；不默认执行全仓 doc-sync。示例见 [识别样例](references/examples.md)，定向检索见 [检索提示](references/recall-batteries.md)。
