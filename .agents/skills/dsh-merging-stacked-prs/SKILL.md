# 堆叠 PR 的授权处理

本仓库不强制 DeepSeek Harness 的标签、官方栈 API、trunk 名称或 CI 矩阵。先读取用户指定的 PR 和当前依赖关系，不能把本技能视为创建栈、改写分支、合并、关闭 PR 或删除分支的授权。

若用户只要求审查，输出依赖、风险和具体行动范围。实施前完成已授权准备并列出准确 PR、分支、基准和合并顺序；远端破坏性操作按用户明确确认执行。检查实际可用工具，不猜测某个 gh 扩展或自动改用不同合并策略。

沿用 [提交前验证](../dsh-pre-push-checks/SKILL.md) 的最小充分证据；上游历史流程只作参考，不能宣称未运行的检查已通过。
