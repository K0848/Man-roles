# Man-roles Roleplayer

向古人问惑的可运行产品插件。它负责困惑对话、人物分支隔离、资料检索、证据校验和安全边界；DSH runtime 负责通用 Agent 执行生命周期。

## 安装与启动

1. 准备与 `dsh-runtime.lock.json` 匹配的 DSH runtime。
2. 配置本地模型 Provider、模型名称、凭据和独立数据目录。
3. 按 `scripts/start-man-roles.ps1` 启动产品 profile。
4. 首次运行前确认资料目录和 preset 能被 profile 访问。

## 数据与安全

- 用户对话、凭据和运行数据不保存在 Git 仓库内。
- 人物分支分别维护私有上下文，另一人物的回答不会自动进入当前人物上下文。
- 资料回答必须关联可用出处；证据被质疑或撤回后不会继续作为有效依据。
- 高风险请求由产品安全规则拦截，不进入人物推理链。

## 开发

源码位于 `src/`，测试位于 `tests/`。构建产物不是事实来源；修改源码后按项目脚本重新构建并运行对应测试。
