# 单中文文档维护

活动文档只维护一份中文 canonical `.md`，不保留 `.zh.md` 镜像、逐页跳转或另一份英文正文。[根 README](../../../README.md)、[文档导航](../../README.md) 与所属模块说明负责当前事实；代码、API 标识、源码 JSDoc 和必要许可原文保留原语言。

## 正文与生成内容

人工说明直接编辑其所属普通 Markdown。生成目录和生成区域由源码及生成器拥有；生成器输出的静态标题、表头和说明使用中文，保留 API 名称和原始 JSDoc。不得手改生成输出掩盖源信息问题。

[路径投影实现](../../../scripts/documentation-paths.ts) 按正式目录重新定位链接，生成器与文档站读取同一份 canonical 正文，不再发现语言副本或按语言回落。既有 `/en/` 兼容路由可发布相同中文内容，不代表有英文维护义务。

## 维护与验证

不创建 sidecar，不执行翻译配对、brief、回录或翻译 merge driver。确有独立翻译交付需求时只处理明确目标，不恢复全仓语言镜像。

正文切换或目录迁移同步实际入链。原有显式锚点、确有消费者的标题片段及 API/类型稳定锚点定位到真实章节；不为假设外部链接给每个旧标题自动增加别名。代码围栏、类型等价、生成新鲜度、链接和 Agent Note 结构继续按各自职责检查，见 [文档规则](../../AGENTS.md)。

## 历史与原文边界

[冻结归档](../../../.agents/notes/archived/AGENTS.md)、vendor 上游原文、许可及机器测试文本不参加人工正文归一。封存 sidecar 只保护历史，不要求活动文档继续建立配对。已有本机 Git 配置不因语言政策改变就被静默删除。

历史翻译工具不属于活动维护链，取代关系见 [中文维护决策](../../../.agents/notes/implemented/process/2026-11-03-man-roles-language-maintenance.md)。翻译样例和术语只作特定参考，不反向规定日常维护流程。
