# 稳定事实与风险

## 必读事实

- 产品首批面向对中国哲学、传统文化或历史人物有兴趣且愿意多轮反思的用户，按小众产品验证，不预设大众市场规模。
- DSH 是通用运行底座；man-roleplayer 通过替换 Provider 实现领域 Harness；人物 Skill / persona 只负责人物能力与表达规则。
- 产品核心任务是澄清用户矛盾并推进判断 / 行动，不是单纯生成多人物角色回答。
- 跨人物仅共享用户确认的困惑状态；其他人物回答和未经确认的导演推断默认隔离。

## 当前有效风险 / 坑

| ID | 风险或坑 | 影响 | 处理方式 |
|---|---|---|---|
| F001 | 把导演推断写成用户事实 | 上下文漂移并误导后续人物 | 状态区分 `candidate` / `confirmed`，只有用户确认后才能升级 |
| F002 | 角色口吻掩盖现代推演 | 用户误以为建议是先哲原意 | 输出强制区分史实、思想解释与现代推演 |
| F003 | 澄清循环追问过多 | 用户退出，任务反而更难 | 每轮限 1～2 个关键问题，并提供跳过 / 结束出口 |

## 环境与契约注意事项

- `AGENTS.md` 是项目规则的单一入口；未来若新增 `CLAUDE.md`，只做兼容转发，不复制项目规则。
- 事迹原文不整体常驻上下文；摘要可进入演员上下文，原文通过出处指针按需取回。
- MVP 只做王阳明单人物；曾国藩、多人物树和复杂剧情投影均为后续范围。
